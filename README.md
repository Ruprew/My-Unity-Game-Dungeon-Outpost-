
# Dungeon Outpost (2D Shooter Game)

A 2D survival action game built in **Unity** to test and expand my C# programming and game development skills. In this game, you play as a character trying to survive, shoot, and outrun relentless monsters hunting you down.

## Features & Mechanics
* **Dynamic Player Movement & Combat:** Run, dodge, and shoot enemies in real-time.
* **Monster AI:** Enemies actively track and hunt down the player.
* **In-Progress Coin System:** An upcoming economy system for collecting coins and items during gameplay.
* **Custom C# Scripts:** Built entirely from scratch using custom scripts for game logic and controls.

## Built With
* **Engine:** Unity (2D)
* **Language:** C#

## Future Improvements
* Finalizing the coin collection and scoring system.
* Adding wave-based enemy spawning and distinct monster types.
* Polishing UI and sound effects.
